Connect reuses the device chosen last time without asking again. WebUSB recognizes each board by its USB serial number; Web Serial cannot tell two identical boards apart, so check the roles (A drives the trigger line).

Capture

GPIO trigger: connect the trigger pins of both boards (and of the reference transmitter, if used) and their GND. The receivers need firmware with TCAP, the reference transmitter with REFTX.

Reference transmitter

MAC Frames RSSI avg / max Type

A third board drives the trigger line and sends one 802.11 frame per capture: the reference. Addressed to a station (Target MAC), that station answers with an ACK 10 µs later: the target. TX delay is the time from the trigger edge to handing the frame to the Wi-Fi driver; negative values hand it over first and raise the line from a timer interrupt. The driver needs about 730 µs until the frame starts, so −700 µs opens the snapshot about 30 µs before the frame. Only address your own devices.
